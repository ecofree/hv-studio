# hw-002 单幕场景归并规划（S2 · 扩充版）

> 用途：把 93 个 frame（逐句）归并到 **22 个可复用场景资产**，
> 让生图量从 93 张降到 22 张（+少量关键新图），验证「场景复用」能否撑起 5 分钟成片。
>
> 归并原则：同一场景的多个镜头，靠 **机位 / 光线 / 前景** 三轴派生打破重复感，
> 而不是每个镜头都重新生图。

> **关键结论**：时长 +48%，成本只 +15%。因为新增内容大多落进**已有场景**
> （如"许给官职牛羊"并入草原羁押、二次出使并入长安/使团场景）。
> 这就是场景复用随篇幅增长的复利效应——**篇幅越长，单分钟成本越低**。

## 派生三轴（防"同一张图连播"）

1. **机位**：wide（建立）→ medium（叙事）→ close_up（情绪）→ insert（器物/细节）
2. **光线**：晨 → 正午 → 黄昏 → 夜/火光（同场景不同时刻）
3. **前景**：帐篷杆、草叶、旌节、竹简、货摊，制造景深

**示例 —— SC08 草原羁押（7 镜，全场景最多）**
```
wide 草原全景·晨 → medium 毡帐前胡妻与孩子 → close_up 张骞手持汉节
→ insert 牦牛尾磨秃特写 → wide 匈奴贵族许官场景 → medium 牛羊群
→ close_up 张骞独立草原望向东方
```
