# 抖音吸引力与字卡规范（v2）

日期：2026-10-20。适用范围：`初唐异人传`、`大唐修罗场` 及后续 v2 历史解说长片。
本文把“前 3 秒、幕间留存、封面/标题、字卡安全区”的调研结论落成可执行规范；
具体某一集的文案仍由人定稿。

## 一句话结论

长视频在抖音的入口不是“慢慢铺垫”，而是**第一帧就给一个具体、反常识、且本片能兑现的承诺**；
幕卡不是目录，是每一次跨幕前的**二次钩子**。字卡只负责把承诺说清楚，不能遮脸、压字幕、挡平台 UI，
也不能用标题党换取点击。

## 调研依据（只取能落地的部分）

| 结论 | 依据 | 对本项目的动作 |
|---|---|---|
| 前 3 秒是留存闸门，用户划走极快 | 迅课《黄金三秒》拆解：前三秒很大程度决定是否继续看；行业分析常引用“平均 1.2 秒/条”的滑动决策，但这不是抖音官方固定值，只作方向 | 标题卡从第 0 帧就完整可见，不做 400ms 淡入；钩子必须具体 |
| 完播率不是唯一指标 | 2025 年后多篇算法拆解强调：完播率是“入场券”，长视频更看平均观看时长、5 秒留存、互动与留存曲线 | 19 分钟片不追求“短”，追求每幕有信息增量、幕边界不塌 |
| 封面/标题决定点击，但必须与内容一致 | 抖音《社区自律公约》明确治理标题党；2026 年《漫剧内容创作建议》把“封面与片名不一致”列为红线 | 钩子可以反常识，但不能虚构；标题必须在本幕内兑现 |
| 幕间是第二次流失点 | 留存曲线拆解建议把骤降点推到 50% 之后；幕卡是低成本“再承诺” | 每幕开头用具体动作/数字/代价做二次钩子，而不是“第 N 幕”报幕 |
| 字卡要短、要大、要避让 | 移动端安全区、封面信息效率的通用做法：主体占画面 1/3–1/2，文字避开右侧按钮与底部字幕 | 主标题 ≤18 字、副标题 ≤26 字；上方天空带优先；高位主体用 `anchor_y` 下移 |

## 字卡规范

| 项 | 规范 |
|---|---|
| 文件 | `episodes/<id>/overlays.json`，独立于字幕表；字幕有逐字保真校验，标题不是旁白 |
| 片头卡 | `0–3800ms`，`fade_in_ms=0`（第 0 帧就有字），末尾 400ms 淡出 |
| 幕卡 | 从该幕第一个 narration unit 的 `sample_start` 起，`2800ms`，400ms 淡入/淡出 |
| 字号 | 片头主标题 132px、幕卡主标题 104px、副标题 68px、集数 54px；超宽自动缩字号 |
| 字数 | 主标题 ≤18 字，副标题 ≤26 字；超过直接判无效，不静默截断 |
| 位置 | 默认片头 `anchor_y=0.20`、幕卡 `0.18`；二人中景/马头等高位主体用 `0.66`；范围 0.05–0.95 |
| 对比 | 片头 `dim=0.32`、幕卡 `dim=0.22`，`scrim=true`；白色文字 + 黑描边 |
| 结构 | 第一幕并入片头副标题，避免前 6 秒连叠两张卡；第二幕起各自成卡；不允许重叠 |
| 自动装配 | `app/services/overlay_author.py`；`compose` 阶段在缺失时自动写，已有文件绝不覆盖 |
| 旧管线 | legacy 仍用 `bin/build_overlays.py`；不要把两套定位口径混用 |

## 文案公式

1. **反常识断言**：`玄奘是偷渡出境的` —— 直接推翻“御弟/文牒”的集体记忆。
2. **具体数字 + 代价**：`五升水，洒进了流沙`、`十八天，无人应战`、`十九年，一千三百多万字`。
3. **动作 + 悬念**：`向导半夜拔出了刀`、`他掉头往回跑了十多里`。
4. **损失前置**：`翻过天山，少了三分之一`。
5. **禁止**：`震惊`、`最`、`必看`、`你不知道的真相` 这类无法在本片兑现的词；不要伪造引语；
   数字必须有脚本依据。标题党会被平台治理，也会把观众预期拉高后摔得更重。

## 每集执行清单

1. 先写一句开场钩子（≤18 字），再写第一幕副标题（≤26 字）；钩子必须是本片真实内容。
2. 每幕标题从“本幕的具体转折”提取，不要直接把文档 heading 当标题；幕卡可以剧透一个动作，
   但不要剧透本幕的最终结果。
3. 整集任务在生图前补齐并检查字卡，单独合成走同一入口。已有字卡保留，改写后重新合成。
4. 抽帧检查：`t=0`（必须有字）、`t=2s`、每幕起点 +0.6s；检查脸、字幕、右侧按钮、底部 UI。
5. `overlay.load` / `validate` 必须通过；`verify` 必须通过；审核人仍由用户本人签署。
6. 发布后看 3s/5s 留存、平均观看时长、幕边界流失、完播与互动；小样本只作线索，
   不要用单条视频的百分比承诺下一集。

## 审核时只看这几件事

- [ ] 第 0 帧有主标题，不是空白或只有底图。
- [ ] 主标题 ≤18 字、副标题 ≤26 字；手机宽度下一眼能读完。
- [ ] 不挡人物脸、关键道具、底部字幕、右侧互动按钮。
- [ ] 幕卡时间等于该幕第一句旁白起点；卡与卡不重叠。
- [ ] 钩子在本幕内兑现；没有为点击而虚构的数字或引语。
- [ ] `overlay.validate`、`compose`、`verify` 全过；用户本人完成看片审核。
