# lishimin-01 改善方案（2026-09-08）

> 针对两条反馈：**① 不通顺的地方很多（整体性）② 语音太平、没有起伏**。
> 本文只给方案与依据，未改代码。每条都附可复现的证据。

---

## 一、先说结论：这两个问题不是一个量级，别混在一起修

| 问题 | 性质 | 影响面 | 解法 |
|---|---|---|---|
| 不通顺 | **系统性**（逐帧合成把"话题—述题"劈开） | 100% 的帧 | 机制解决，一处改完全篇受益 |
| 太平 | **配置问题**（音色 prompt 自己写的"平稳"+ 高级参数没用） | 全片 | 改配置 + 启用已有参数 |

**关键：不通顺不该一处一处补。** 你记得的那几处只是样本，实际每一帧
结尾是「，」且下一帧是述题的，都有同样的问题——这类帧占大多数。
逐个改分镜是打地鼠，改合成粒度才是根因。

---

## 二、问题① 不通顺：机制解决

### 根因（实测）

每帧独立合成后，帧间有约 **300ms 首尾静音**（实测中位 首162ms / 尾252ms）。
汉语大量使用「话题 + 逗号 + 述题」结构，被切在逗号处时：

```
帧26「在隋炀帝把百万中原士卒扔在高句丽泥潭里的那一刻，」
        ⟵ 约 300ms 空洞 ⟶
帧27「算盘就已经打得震山响了。」
```

听感上就是"话没说完就断了"。帧 34/35、36/37、28/29 同构。

### 另有两类独立缺陷（与粒度无关，要单独修）

**`——` 被念出来（6 帧，ASR 实听）**
```
帧11  原文「……孤本——」       识别「……孤本。」          ← 变硬句号
帧59  原文「唯一选择——把…」    识别「唯一选择。马琳把…」    ← "马琳"是破折号的杂音
帧80 / 94 / 136 / 191 同帧11
```
音频里毫无意义，必须在送 TTS 前剥掉。

**硬切 2 处**（`_balanced_split` 在无逗号长句里中分，切在词中）
```
帧54   「……西秦铁骑甚至打」+「到了离长安只有几十里的浅水原。」
帧160  「一边是天策府内部几百名百战功」+「臣面临被和平解散……」  ← "功臣"被切开
```
判据：无标点收尾的帧 = 硬切。全篇 220 帧只此 2 处。

### 改法

| # | 动作 | 效果 |
|---|---|---|
| A1 | **默认回到段落级** | 连续音频 → 帧间只剩 6~7ms，一次性解决所有"话题—述题"断裂 |
| A2 | 送 TTS 前剥掉 `——` | 修 6 帧 |
| A3 | `_balanced_split` 避开词中切点 | 修 2 帧 |
| A4 | 易错词表 + 命中帧逐帧降级 | 保住断词正确性（晋阳令/刘文静），代价只落在个别帧 |

A4 是必要的：段落级会把「晋阳令刘文静」读成「晋阳 / 令刘文静」
（实测 ≥45 字必错）。降级只针对命中易错词的帧，其余全走段落级。

## 三、问题② 太平：三个杠杆，其中两个是白捡的

### 根因（这次查出来的，很具体）

**音色设计 prompt 里自己写了"要平"**（`cosyvoice.py:245`）：

```
"一位沉稳的中年男声播音员，声音低沉浑厚、富有磁性，语速平稳，吐字清晰，
 适合历史纪录片旁白或新闻播报。"
```

「语速平稳」+「新闻播报」= 直接指示语音设计产出平铺直叙的播报腔。
这套描述是给新闻播报场景写的，套到戏剧化历史解说上必然平。

**而代码里早就有的高级参数，一个都没用上：**

| 参数 | 位置 | 现状 |
|---|---|---|
| `instruction` 自然语言风格指令 | `cosyvoice.py:446` 已发送、`config.py:145` 已声明 | **管线从未传入** |
| `pitch_rate` 音调倍率 | `cosyvoice.py:440` | 未用 |
| `speech_rate` 语速倍率 | `cosyvoice.py:442` | 未用 |
| `cosyvoice-v3.5-plus`（高档位） | `cosyvoice.py:197` 注释已列 | 默认用最低档 flash |

### 改法

| # | 动作 | 说明 |
|---|---|---|
| B1 | **重做音色 prompt** | 去掉「语速平稳/新闻播报」，改成戏剧化：低沉有磁性的中年男声、**抑扬顿挫、快慢有致、善用在关键处停顿与加重**、适合有叙事张力的历史解说 |
| B2 | **启用 `instruction`** | 零实现成本（代码已就绪）。给一句风格指令，如「用低沉、有压迫感、抑扬顿挫的语气朗读，关键处放慢加重」 |
| B3 | **升 `cosyvoice-v3.5-plus`** | ¥1.5/万字符 vs flash ¥0.8/万。14.6min 片（3630 字）**¥0.54 对 ¥0.29**——绝对值可忽略，但音质与韵律是更高档位 |
| B4 | （进阶）**按段落给不同 instruction** | 让整片有起伏而不是一个调：紧张段「急促压抑」、抒情段「低沉缓慢」、转折处「突然停顿」。剧本里的【导演标注】可以直接驱动这个 |

B4 是我最推荐追加的一项——**真正的"起伏"来自段落间的对比，
不是全局调一个参数**。剧本本来就有【导演标注】，那是最现成的情感信号源。

## 四、验证方式：先 A/B，别拿全片去赌

全片重跑 = TTS ¥0.54 + 渲染 38 分钟。**先花约 ¥0.05 做 A/B 试听**：

用同一段有戏剧张力的文本（建议帧 205~216「六月初三夜」，本身就有紧张感），
出 4 个样本：

| 样本 | 配置 |
|---|---|
| S0 现状 | flash + 旧 prompt（基线） |
| S1 | flash + 新 prompt |
| S2 | plus + 新 prompt |
| S3 | plus + 新 prompt + instruction |

你选一个，再全片重跑。
