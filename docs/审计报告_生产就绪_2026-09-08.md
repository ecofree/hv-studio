## 二、P0（阻断正式生产，已确认 3 条）

### P0-1｜音频指纹不含引擎/策略维度 → 切换引擎静默复用旧音
- **证据**：`voice.py:98-101` `_text_fingerprint` 只 md5 文本；幂等检查
  `voice.py:388/471` 只比 fp。engine、qwen_model、rate、SSML 档位全不在内。
- **今天的实证**：我被迫手动 `mv` 音频目录 **6 次**才让新配置生效——
  每一次都是这个缺陷的人工代偿。
- **后果**：任何人切引擎/调参后不手动清目录 → 整集静默复用旧音。
- **修复**：fp 加入 `engine + model + ssml策略版本`（或在 manifest 记策略版本号）。

### P0-2｜qwen 配额 403 无分类、无预检、无断点收口
- **证据**：`voice.py` 瞬时判定复用 image 的 `_TRANSIENT_SIG`（image.py:49-57），
  含 429/503 但 **403 FreeTierOnly 不命中** → 一次即弃；报错只截 120 字符
  不提示「额度耗尽」；无合成前额度预检；qwen 分支无降级路径直接 raise。
- **今天的实证**：plus 和 flash 额度先后耗尽，两次都靠我人工诊断。
- **修复**：403/AllocationQuota 单列为「致命-额度」类，报错直说「额度耗尽，
  模型 X 剩余 Y」；tts 前置额度预检或按字符数估算。

### P0-3｜双进程并发零防护
- **证据**：全仓无 filelock/flock/msvcrt；`episode.json` 后写覆盖先写、
  `_tts_manifest.json` 整表覆盖、segments/out 同名互踩。
- **修复**：episode 级文件锁（`episodes/<id>/.lock`，PID 存活检测 + 陈旧回收）。

## 八、生产就绪判断

- **现在就能继续做片**（单进程、一次一集、你在旁边盯着）：可以——今天这部片就是证明，且质量数据（PER 0.0~1.2%、起伏达标、无英文串）是全程最好的
- **挂机批量出片**：不行。配额耗尽（P0-2）会 403 中断且无断点收口；双开进程（P0-3）会互相覆盖；切引擎（P1-4）会静默读错多音字
- **最小收口包**（止血阶段 0.5 天）做完后：可以挂机单集生产；批量多集仍建议文件锁先上
