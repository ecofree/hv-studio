## 后续执行规则

| 范围 | 何时运行 | 入口 |
| --- | --- | --- |
| `production` | 默认验收；当前 V2 入口、原稿、预算、音色/缓存身份、拒用音频、对齐、字幕、渲染及图片路由 | `scripts/ai-project-check.ps1` 或 `python -m pytest` |
| `shared` | 修改图像重试、ASR 适配、清理、日志、配额、音视频公共组件时 | `scripts/ai-project-check.ps1 -Suite shared` |
| `legacy` | 明确修改旧预览、旧分帧、Qwen 等保留入口时 | `scripts/ai-project-check.ps1 -Suite legacy` |
| 全部 | 大范围兼容性审查，有具体理由再运行 | `scripts/ai-project-check.ps1 -Suite all` |

Python 使用项目 `.venv-core/Scripts/python.exe`。指定测试文件仍受默认 production 选择影响；检查共享组件时同时传 `-m shared`，检查旧流程时传 `-m legacy`。需要忽略范围选择时传 `-m ""`。

新测试必须明确标记 production/shared/legacy；默认验收不再因新增一项历史兼容测试自动变慢。以后只针对改动可能破坏的行为验证，不再机械要求每次把全部测试跑一遍。
