## 分幕设计

| 现有时间范围 | 视觉设计 | 注意力安排 |
|---|---|---|
| 0–2.30 秒 | 宫室背景轻移，局部烛光低强度起伏 | 第一帧标题保持完整，环境让位于悬念 |
| 2.30–16.22 秒 | 窗外雨丝由弱到可见，远景产生细微相对位移 | 两个连续同图镜头共享动画时钟，雨场不在 7.24 秒重新开始 |
| 16.22–32.74 秒 | 托付双手保形；手部近景、跪姿镜头的窗景与烛光分别处理 | 遗言段逐渐减速，面部、手部、冠饰和衣袍不做变形 |
| 32.74–40.90 秒 | 雨和位移进一步减弱，暖光维持低强度 | 为“温情契约”转向“枷锁”留出空间 |
| 40.90–55.96 秒 | 宫室与远门采用不同位移；“不是倚仗”段停止新增视差，雨/光淡出 | 约 49.32–51.72 秒新增动画保持静止，保留原有镜头运动与声音 |
| 55.96–75.80 秒 | 正面帝王原画增加殿外远景/近处栏杆两层变化；相邻宫室镜头反向微移 | 空间变化帮助观察人物位置，不增加人脸动作或额外视觉符号 |
| 75.80–84 秒 | 延续上一镜的背景相位，缓慢展开并在最后约一秒落稳 | 让“史书的另一面”引出后文，标题与原声保持原样 |

表中沿用原始样本时钟的秒数。视频边界按项目既有 25fps 就近取帧规则量化，例如 16.22→16.24、40.90→40.92、51.70→51.72；没有重排或拉伸旁白。

所有分层只在原画可见的背景区域内采样，人物仍是完整原画层。没有补画人物背后，不支持绕人运镜或大幅人物分离。光照仅在可见烛灯附近变化；雨不越过窗外蒙版与人物保护区。

## 工程变化

`scene_animation` 保留已有三类效果，增加两个导演能力：

- `frame_range`：连续同图镜头共用完整动画区间。此次绑定 `[58,406]` 与 `[1758,2100]` 两段。
- `progress` / `envelope`：单层位移进度与雨/光强度曲线。各键间平滑过渡，支持减速、停住、淡出；位移曲线不倒退，参数与时间范围非法时失败。

原有未配置曲线与共享区间的三个小样仍采用旧的默认时间行为。动画参数和新模块源码继续进入片段缓存指纹，改变停顿或曲线不会复用旧画面。

新增 `bin/build_animation_preview.py`：先校验基准素材哈希，要求设计逐一覆盖现有镜头，预检各蒙版，再把 animation 字段加入原时间轴。剥离 animation 后的镜头、字幕、声音、标题和相机数据必须与基准完全一致。正式渲染继续使用现有 production_v2，保留断点、片段缓存、媒体验证与候选片回执。

## 交付证据

输出目录：`state/creative-pilots/xlc-01-animation84-20261018/`。

- `animation-design.json`：逐镜头目的、强度、共享时钟、背景与保护区；绑定基准影片、母带、原时间轴、原清单与作者脚本。
- `timeline.json`：完整 84 秒动画时间轴。
- `result.json`：指向 v2 正式候选回执；回执绑定输入、源码、配置、运行时、片段和最终视频。
- `baseline-inputs.json` / `source-before/`：本轮改动前指纹及相关源码备份。
- `mask-verification.json`：每镜首/中/尾的真实原画保护区像素核对，以及连续同图镜头的相位检查。
- `review/shot-and-cut-contact.jpg`：编码后逐镜中间帧，以及各镜首尾帧，供检查遮挡、人物、字幕与边缘。
- `acceptance.json`：项目 production 检查，268 passed、311 deselected；这是代码/运行环境证据。
- `final-verification.json`：当前源码与验收指纹、输入漂移、原始文件保留、84 秒/2100 帧/2,016,000 样本、混音字节一致、两版解码音频一致、字幕原文与几何、输出哈希。

渲染命令（长任务应通过隐藏的 `Start-Process` 分离运行并重定向日志）：

```powershell
.venv-core/Scripts/python.exe bin/build_animation_preview.py --design state/creative-pilots/xlc-01-animation84-20261018/animation-design.json --output state/creative-pilots/xlc-01-animation84-20261018
```
