# Qwen 本地配音：统一声音与独立运行

所有新配音沿用作品已绑定的系列声音。制作页、`bin/studio_narrate.py`、`start_qwen3_tts.bat` 和旧脚本兼容启动器调用相同实现。没有预算的方案预览不启动模型；实际配音仍使用原有持久预算。旧的本地 HTTP、独立默认音色和直接加载回退不再执行。

## 声音方案

- 保持原有说话人、模型、语言、采样参数、目标倍速和已选音轨；不自动转用克隆模型或其他说话人。
- 已确认合同与历史试听证据不改写。新请求记录执行政策与代码指纹；只删除已识别的 Dylan 旧试听句“第一段松弛地铺陈……第三段讲清通关规矩和越境代价”。其他声音的指令不受影响。
- 每段种子由系列种子、声音参数和准确正文派生，不依赖集号、段号、顺序或缓存是否命中。工作器在每次推理前重置 Python、NumPy、Torch 和 CUDA 随机状态。
- 旧回执按原请求核验，旧音频不覆盖。新请求使用新的缓存身份。程序、显卡或运行版本变化后的逐样本一致性不作保证。
- 局部补录仍需同一声音方案与原有预算；失败和不确定结果不自动重试。

## 独立运行

解释器固定在本项目 `.venv-qwen3-tts`，工作器固定为本项目 `bin/qwen_worker.py`。归档合同中的 `runtime_python`、`worker_path` 是历史证据，不作为执行地址。现有模型目录 `D:/models/qwen3-tts` 是可独立保存的权重数据；项目不导入该目录中的服务脚本。

保留旧地址用于追溯与在当前项目内定位对应文件。地址解析不探测原项目，也不在本地文件缺失时回退。`.studio-project.json` 中的旧目录列表不是依赖。启动器拒绝把 `HV_PYTHON` 指向已退出使用的项目。

常规验收会自动检查旧目录依赖，也可运行 `bin/check_independence.py --output <报告路径>` 单独检查可执行代码、启动器、运行环境配置、加载路径及环境变量；它不运行模型。跨机器部署仍须安装本项目的 Python 环境、模型权重与 FFmpeg，不能借用另一项目的虚拟环境。

## 声音一致性提示

新候选自动生成 `voice-consistency.json`，读取已有确认记录中带哈希的参考片段，比较分段音高、声谱包络与响度，并覆盖长段的中间和结尾。报告位置使用最终倍速音轨的时钟。

这是一项本地声学筛查：不下载模型，不认证说话人身份，不代替人名、多音字或声调的听审。声音内容和情绪都会影响特征；阈值以现有参考片段的变化范围加保守余量确定。参考缺失、变动或人声不足时明确报告无法判断，不能显示通过。

报告只定位疑点，不增加审批、阻止正常听看或自动重配整集。制作页在原有旁白结果旁提供异常位置试听。历史音轨没有报告时保留原状态，不强迫回放或重配。

## 无配音、无渲染验证

`scripts/ai-project-check.ps1 -ProjectRoot <隔离副本> -NoMedia` 排除需要实际媒体编码的测试。配合隔离验证的进程防护，禁止访问原项目与真实作品、禁止加载模型或编码媒体。种子测试使用假模型，声学测试使用合成测试波形；这些结果证明代码行为，不证明真实长篇听感已达标。
