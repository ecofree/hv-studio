## 保留内容及理由

补充目录的 41,511 行并非都是运行中的系统实现。恢复归档中有大量按哈希保存的源文件，作品与声音方案也绑定过制作脚本；这些属于恢复证据，不能因为扩展名是 `.py` 就删掉。

保留当前本地 Qwen 声音方案实际引用的脚本、按哈希固定的声音工作器、用户提供音频的制作记录、历史作品输入和原始错误日志。独立的历史云配音制作记录没有被当前 v2 自动调用，本次没有执行它们，也不将它们宣称为已经纳入现行预算的生产入口。已安装环境中的旧依赖未强行卸载；当前依赖声明已不再要求 Edge TTS。

这次完成的是全仓清单、调用关系和生产故障驱动的清理，不能由此证明每一行代码都无缺陷，也没有逐个运行历史制作记录。
