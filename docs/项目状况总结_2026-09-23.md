## 0. 一句话定位

**已从「单集手工出片脚本」演进为「无人值守候选片生产系统」**：以 9 阶段 v2 流水线为内核，
外挂「单 owner 持久队列 + 内核锁 + 预算账本」，所有产出都是不可变候选，
只有经输入准入 → 逐 take ASR 质检 → 声学对齐 → 人类双审（视觉+听审）后才允许发布。

当前规模：**app/ 14007 行 / 47 个 services 模块 / 41 个测试文件 / 15 个 episode / 26 份文档**。

## 1. 已实现功能

### 1.1 视频生产主链（9 阶段，`episode_production.py:17`）
```
script → images → tts → delivery → quality → alignment → timeline → compose → verify
```
- `orchestrator.produce()` 是唯一调度入口，v2 转调 `episode_production.run`（`orchestrator.py:800-809`）
- 集级 `.produce.lock`、磁盘预检、显式预算在阶段启动前校验

### 1.2 无人值守生产（近两周主要演进方向）
| 能力 | 实现 |
|---|---|
| **持久队列** | `batch_worker`（单 owner + `worker.lock`），每集 spawn 子进程 `bin/production_worker.py --execute` |
| **失败隔离** | 失败写 `errors/`，其余任务继续；RUNNING 行重入先收尸 |
| **断点续跑** | `queue-retry` 受控续跑，保留累计尝试数 |
| **暂停/急停** | `PAUSE`/`STOP` 检查点文件；owner 死亡看门狗杀光子进程 |
| **预算控制** | `ProviderBudget.reserve` 派发前扣费、失败不退；批次共享一本账；**默认额度为零** |
| **输入准入** | `production_admission.check` 需 scene_plan + image_prompts + scene 引用完整 + 艺术指令有执行计划 |
| **人工审核** | `record_approval` 写 `input-approval.json` 并与 `input_fingerprint` 哈希绑定 |
| **质检** | `production_quality` 逐 take ASR 回检；`record_disposition` 为人类专属 |
| **发布闸** | `production_status.approved` 需视觉+听审双审且无 pending；`production_readiness` 要求心跳新鲜 + ≥2 集验收 |
| **资产复用** | `video_segment_cache`（哈希+帧数双验）、`production_backup`（快照/校验/恢复） |

### 1.3 语音与字幕链
- **TTS**：cosyvoice-v3.5-flash / qwen-audio-3.0 双引擎；SSML 逐句标注（rate 定起伏 + phoneme 定读音）；帧首尾静音裁剪；ASR 回检闭环
- **字幕**：`spoken_text`（仅改标点的规范化）→ `local_asr`（隔离 worker）→ `forced_alignment`（词级时间）→ `subtitle_layout`（唯一度量契约）→ `alignment_review_page`（本地试听页）

### 1.4 生图
- 三路并行 + 渠道钉住（每渠道一路，防 429 退化单路）
- 按模型能力路由（`image.py:191` 只打 `channel.supports(model)` 的渠道）
- 成本台账 + 图片复用（`existing_images` / `reuse-images`）

### 1.5 运维工具
`hv batch`（批量+失败隔离+续跑）、`hv backup`（底图冷备，保留 mtime）、`hv gc`、`hv smoke`（零成本全链冒烟）、`hv clean`（中间产物，白名单制）、`hv queue-retry`、`hv input-review`
