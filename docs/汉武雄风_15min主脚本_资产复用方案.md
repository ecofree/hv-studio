#### 正文（初稿）

- 公元前二〇〇年，汉高祖刘邦率三十万大军北击匈奴，却被围在白登，七天七夜。
- 靠贿赂单于阏氏，才侥幸脱身。从此，大汉对匈奴，低下了头。
- 吕后当政，单于来信轻慢，朝堂震怒，却也只能忍气吞声，送公主和亲。
- 高祖、惠帝、文帝、景帝，一代又一代，汉家把女儿送进大漠，把屈辱写进史书。
- 直到公元前一四一年，十六岁的刘彻登基。这个少年望着北方，心里只有一个念头：雪耻。
- 他问满朝文武：要等到何时，大汉才能扬眉吐气？
- 前一二四年，雁门一带传来消息：匈奴入寇。刘彻抓住机会，设下马邑之谋，想诱敌深入。
- 可惜单于识破埋伏，撤兵而去。谋略失败，却也撕破了六十年的和亲假面——汉匈，正式开战。
- 同年，年轻的卫青，率一万铁骑，直捣匈奴祭祀圣地——龙城。这是大汉立国以来，对匈奴的第一次大胜。
- 捷报传回长安，未央宫里，刘彻第一次感到，雪耻有了可能。
- 单于在龙城受辱，怒不可遏。他连年入塞，烧杀掳掠，逼汉朝再度决战。
- 而卫青没有给他机会。河朔、漠南，一仗接一仗，汉军把战线，一步步推过大漠。
- 军中又冒出个少年——霍去病。他十七岁随军，八百骑孤军深入，斩获两千，被封冠军侯。
- 人们说，这少年生来就是为打仗的。他打河西，夺祁连，让匈奴悲歌：失我祁连山，使我六畜不蕃息。
- 前一一九年，漠北决战。卫青、霍去病各率五万骑，横越大漠，与单于主力正面决战。
- 此役，匈奴主力被歼，单于远遁。霍去病在狼居胥山祭天，封狼居胥——那是汉军从未到达过的远方。
- 自此，漠南无王庭，匈奴远遁大漠以北。六十年的边患，终于被这一代人打了回去。
- 可刘彻知道，光靠打，守不住。要彻底制服匈奴，得找到它西面的敌人，与之联手。
- 于是，他把目光，投向了那片从未有人真正走过的西域。——这，就是下一章的故事。

## 4. 拼接与合成方案（三章合一，一条 mp4）

hw-002 已经是**独立成片**，不能简单当素材拼接（每章有自己的时间轴/音画对齐）。两条合成路线：

**路线 A（推荐 · 幕级 compose 拼接）：** 三章各走完整的「场景派生 → 关键新图 → Ken Burns → 字幕 → TTS → compose」产出一段 mp4/或分幕 wav+raw 帧，再用 ffmpeg concat（同码流参数，无缝）。张骞章直接复用已产出的 `hw-002_m1.mp4`。
- 优点：每章独立断言（防音画漂移），张骞章零成本复用；失败只重做单章。
- 缺点：需确保三章同 profile（High/4.1/44100mono/25fps/1080×1920）才可 concat。

**路线 B（单 episode 长片）：** 把三章合成一个新 `episodes/hanwu15`，一次性 compose 全 15min。
- 优点：单一文件无拼接缝。
- 缺点：~22k 帧一次性合成，内存/时长风险大（docs §4.3 已警示），且要把张骞章从 hw-002 迁入——改动已定稿资产，回归成本高。

> **决策：走路线 A**。三章独立产片 → `ffmpeg concat demuxer` 无缝拼接（先 ffprobe 校验码流一致）。张骞章用现成 mp4，全片 ≈ 一次 concat + 两章新 compose。
