# 系列文案、声音与整集制作

2026-11-05：以 `studio-workflow-policy.md` 为现行流程。下文创作卡、逐段史料和视频样片仅为可选编辑工具；确认当前正文关键史实并选择声音、明确预算后可直接制作旁白。完整听看与本地成片确认已接入成片制作页。原稿与技术检查仍保留。

本流程不改写原稿。原项目和历史材料继续保留。声音参数的沿用不继承旧集的音轨、字幕或成片批准。

1. 在左侧“从同步原稿建立新版本”逐字导入作者原稿、TTS 对照稿和规则。原稿与 TTS 正文冲突时停止导入，由作者处理；不自动选稿。
2. 在“样片试听 → 系列共用声音方案”选择已确认方案，点击“将共用声音方案绑定到当前新稿”。记录原稿与规则指纹，逐字划分配音段落，保持说话人、模型、统一指令、生成参数和累计倍速。只有草稿 metadata 改变，不会开始生成。
3. 完善本集创作卡、逐幕画面及实际审核。新建独立短样片时沿用声音方案、重新绑定所选原文；不复制原集的审核。
4. 具备制作授权后，在“成片制作”明确本次预算，选择“先制作旁白候选”。已返回的原始配音保留；漏读、重复、长静音问题会阻止合并，不会自动重配。
5. 候选完成后点击“选用这条旁白制作整集”。系统核对实际配音请求、原文覆盖、原始录音、内容检查、倍速和音量处理链；只写选择记录。旧音轨和旧视频不替换。
6. 再明确提交“制作视频候选”。使用选定音轨进入 v2 的整轨定位、切片、内容检查、字幕对齐、逐幕时间线与合成。视频阶段不再次配音或叠加 1.2 倍速；新音轨必须建立新的字幕时间轴。
7. 关掉页面后任务继续运行。中断后在同一页面点击“按原预算继续此任务”。原请求、文案、声音、选定音轨发生变化时拒绝恢复；预算沿用原账目。未确定结果的配音请求不会自动重发。已完成任务不提供恢复按钮。

系列方案位于 `workspace/state/series-voices/*/scheme.json`。新集绑定为 `studio/voice-contract.json` v2；旧玄奘 v1 绑定继续保留。系列方案保存确认记录及执行器的独立副本；本机模型和运行环境仍须按原版本存在。

整集选用记录位于 `studio/narration-selections/`，`studio/narration-selection.json` 仅作当前指针。新整集制作替换运行登记前，将旧运行记录保存在 `production/v2/run-history/`；旧视频、音轨、字幕和候选记录不覆盖。

人工听看与史实检查仍是成片审核。软件检查通过、沿用声音方案或点击选用，均不会把新集标记为已批准。
