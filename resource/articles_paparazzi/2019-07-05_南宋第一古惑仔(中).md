# 南宋第一古惑仔(中)

“战争中你流尽鲜血,和平中你寸步难行。”刚刚南下归宋的辛弃疾摩拳擦掌，时刻准备北伐做大做强，但很快就发现情况跟自己想象的不太一样：临安这地界好啊，好得过分，俊俏的山水、丰富的物产、婉约的美女，要啥有啥，柔媚的熏风能把直男吹弯。大领导宋高宗赵构早年被金国追着屁股打，被打出了“恐金症”，连生育能力都吓没了，是绝逼不想再跟金国起刺儿的，好不容易摁死主张正面硬刚的岳飞换来几天岁月静好，能重用辛弃疾撩骚那帮鞑子给自己添堵才怪。再者说了，北伐不成功则已，要是成功了，把亲爹亲哥（徽宗钦宗）就地活埋？那太不像话，肯定得接回来供着啊，那要是这俩爷回来……房子这么小，我赵构住哪？所以拉倒，必须拉倒，就此打住，什么北伐？去江阴州府坐办公室吧小子（江阴签判）！

在一个单位里，有些岗位是画大饼糊弄你的，有些岗位是给你点炮儿往上窜的，虽说岗位的发展各有千秋，但想知道领导是不是真的赏识你、想栽培你，别听他口嗨，就看他把你放到哪个岗上，拿资源作为关键衡量点来判断领导的用意，基本没错。办公室文员辛弃疾看看自己手上身下，哎呦，刀枪入库马放南山，连画的大饼都没有！说话没人理，做官做不起，好好的一个堂口揸fit人生生变成了社会闲散。归正人（从金国境内南渡的，南宋有特定的称呼“归正人”），毕竟不受待见啊……

怂归怂，但时不常的被热血子民们diss，宋高宗心里也膈应，于是1162年6月，他在官微上最后更新了一条动态：“人的一生可能会经历各种告别，在我们的相遇中收获的爱和温暖都化为了永恒的力量，感谢一路走来你所有的给予，支持和爱。谢谢未来还会有的关心和爱护。我们不再是我们，我们依然是我们。”随后传位给继子赵昚（shèn），自己躲进后宫当潇洒艺术家去了。新领导宋孝宗赵昚，被后世誉为南宋最有出息的皇帝，刚登基就给岳飞平了反，还在朋友圈各种转发《万里长城永不倒》之类的励志歌曲：昏睡八年，过淫贱一生，睁开眼吧 小心看吧，哪个愿臣虏自认……

有这样锐意进取的领导，辛弃疾当然热血沸腾了，在家拼命总结自己的军事见解，就盼能派上用场。但宋孝宗极有可能是急性子，说整就整那种，没做太多准备，1163年4月就派主战大臣张浚带二十万人（号称）展开了隆兴北伐，与金人不宣而战。

辛弃疾内心应该很凌乱：卧槽直接梭哈这么屌？大力出奇迹是吗？然而大力并没出奇迹。一个月后，北伐部队就被金军干翻在符离。战报传回京城，宋孝宗立刻将朋友圈设为了仅三天可见。

打不过，只好和议，史称“隆兴和议”。和议主要规定：南宋对金国不用见外，别称臣了，直接叫叔就行（宋金世为叔侄之国），另外割地、赔款，一个都不能少。正在江阴的辛弃疾，听说宋军又跪下唱征服了，心潮澎湃难以平静。1165年，他攒了10篇军事论文一口气发送给了宋孝宗，称《美芹十论》，里面分析军事形势，查摆失利原因，提出改进措施，并希望领导能再起抗金救国、收复失地、统一中国的大计。宋孝宗看完：这位网友写得挺好，收藏，但我得缓缓。“符离之溃”对孝宗打击相当大，张浚等主战派人物在符离溃败后陆续被排斥出南宋政府，主和一派抬头，朝中不再是“主战大于主和”的局面了，所以赵昚同志开始在战和之间摇摆不定。

几年后，赵昚同志缓过来了。乾道五年（1169年）八月，宋孝宗召在“采石之战”中大败金军的虞允文入朝，升其为右丞相兼枢密使，掌握军政大权，再议北伐。虞允文一方面在财力、物力、兵力上积极为北伐作好准备，另一方面，他给领导赵昚建议：这次咱别担先挑事儿的名声，派个使者去金国商量改改隆兴和约中的霸王条款，探探他们的底线先。宋孝宗同意了虞允文的建议，于乾道六年（1170年）闰五月派范成大（与陆游、杨万里、尤袤齐名，称“中兴四大家”，个人很喜欢他的《车遥遥篇》）出差金国，向金世宗提了俩要求：一是归还河南祖坟所在地，二是改变宋帝站立接受金朝国书的礼仪。金世宗听完第一条就很生气：哦，你清明祭祖不方便，就要在我的地界划一块特区走？想惹我生气先动手让我理亏是不？老子不上当！于是给了反馈：地不能还，但为了表示我们和好的诚意，我派三十万人马帮你们把祖坟迁到南方去怎么样？

三十万金兵南下，闹呢？宋孝宗连连摆手，算了算了，那什么，坟就不迁了。土地没要成，反倒提高了金人的警惕，对南宋加强了防备，偷鸡不成蚀把米。

这时宋孝宗想起了给他猛发军事论文的网友辛弃疾，就把他叫来面基，交流交流想法。关于这次面基，《宋史·辛弃疾传》是这么记载的：“六年，孝宗召对延和殿。时虞允文当国，帝锐意恢复，弃疾因论南北形势及三国、晋、汉人才，持论劲直，不为迎合。”“持论劲直，不为迎合”，就是辛弃疾坚持己见，不迎合领导宋孝宗。所以，这俩网友见光死了：我住长江头,君住长江尾，有朝一日来面基，卧槽什么鬼？

这就让人困惑了，一个是力图收复中原的最高统治者，一个是热心主战的钢铁大直男，大方向契合，那么分歧在哪里呢？没聊天记录，没法确切知道。就在这次召见后不久，辛弃疾又给宰相虞允文发了一篇军事论文——《九议》。从这篇论文里，大致能看出辛弃疾和宋孝宗面基失败的原因：首先，辛弃疾认为，关于北伐的讨论、决策和行动，都要注意保持高度的机密（“不可白于天下”）。这话矛头直指宋孝宗先派范成大去金国聊骚这件事（范成大：我能有什么办法，我也很无辜啊！）。辛弃疾认为这是在向敌人泄露用兵机密，非常的傻逼。其次，他又指出，北伐行动要“无欲速”，不应该一把梭哈，不然就像小学生的书包一样，除了书（输），就是本：“凡今日之弊，在乎言和者，欲终世而讳兵，论战者，欲明日而亟斗。”就是说，当今最大的弊端，在于主和的人想要永远地避免战争，而主战的人恨不得明天就开打，非常极端，这是万万不行滴！打是肯定要打，但不能操之过急，应该做好长期准备，按“一年准备两年反攻三年扫荡五年成功”这个节奏来，否则就会招致"符离之溃"那样的失败。也不用再说其他七个议题了（主要是本文作者看多了文言文头疼），就开头这两条，处处顶宋孝宗的肺，他听了能高兴到哪里去？

所以这位战狼，咱不聊边疆和战场了，平定内乱和发展经济方面你有何良方？……这次面基后不久，辛弃疾就被调去临安做国家粮食局办公室主任了（司农寺主簿），属于平调，没升。科班带小弟，砍人专业户，结果领导让你干美容美发，专业严重不对口，但你真没招。

怀才不遇，壮志未酬，临安的几年，辛弃疾一直郁郁寡欢，唯一能够遣怀的就是听曲填词了，著名的《青玉案·元夕》就是出于此时：东风夜放花千树，更吹落，星如雨。宝马雕车香满路。凤箫声动，玉壶光转，一夜鱼龙舞。蛾儿雪柳黄金缕，笑语盈盈暗香去。众里寻他千百度，蓦然回首，那人却在，灯火阑珊处。

“全文主要运用了反衬的表现手法，表达出作者不与世俗同流合污的追求（词人对理想的追求的执着和艰辛）”这些，我没解读出来，我倒真心希望一段真挚的艳遇可以慰藉慰藉这位失落失望失掉所有方向的硬汉，哪怕啊，哪怕只能慰藉一点点，哪怕他直到看见平凡也不认为这就是唯一的答案。
