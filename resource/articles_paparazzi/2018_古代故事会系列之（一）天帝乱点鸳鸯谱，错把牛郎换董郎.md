# 古代故事会系列之（一）天帝乱点鸳鸯谱，错把牛郎换董郎

- **发布日期**: 2018

汉朝的时候，山东高青有个叫董永的男青年，老爹死了没钱埋，只好卖身葬父。

当地一个富户知道他孝顺，给了办丧事的钱。董永：东家，我还得给我爹守丧三年，三年以后回来好好伺候你，给你搓澡。

富户：别，我直男。

董永守完三年丧，立刻往主人家赶。他的孝顺和言而有信感动了天帝，决定给他加个buff。

路上，董永遇见一个姑娘跟他碰瓷，俩人一拍即合，就地扯证，董永带她一起去了主人家。

主人问：你会干啥？董永：啥也不会。主人：……你老婆呢？董永说：会织毛衣。主人：那行，给我织几件套头鸡心领，显瘦咱就两清，不显瘦赔我毛线。

于是，董永的老婆就开始织毛衣，手贼快，唰唰唰十天就织完了。主人一试，呦，减龄藏肉！就免了他俩的奴役。

俩人出了门，老婆对董永说：我是天上的织女，天帝派我下来精准扶贫的，债还完了，我就不跟你苦熬了，闪。说完飞走了。

董永：你非要走也行，先圆房嘿！一通狂追。追着追着感觉不对劲，回头一看，后面还有一男一女在追自己。

董永：呦，还有漏可捡，于是和七仙女夫妻双双把家还。

剩下个牛郎特悲愤，只能去夜总会富婆怀里寻找慰藉。

你以为是我喝大了瞎扯淡？并不是，古代故事会里就是这么写的，请看原文：

《搜神记·董永之妻》 干宝

汉董永，千乘人。少偏孤，与父居。肆力田亩，鹿车载自随。父亡，无以葬，乃自卖为奴，以供丧事。主人知其贤，与钱一万，遣之。永行三年丧毕，欲还主人，供其奴职。道逢一妇人日：“愿为子妻。”遂与之俱。主人谓永日：“以钱与君矣。”永日：“蒙君之惠，父丧收藏。永虽小人，必欲服勤致力，以报厚德。”主日：“妇人何能？”永日：“能织。”主日：“必尔者，但令君妇为我织嫌百匹。”于是永妻为主人家织，十日而毕。女出门，谓永日：“我，夭之织女也。缘君至孝，天帝令我助君偿债耳。”语毕，凌空而去，不知所在。
