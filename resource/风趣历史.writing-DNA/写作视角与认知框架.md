# 史料方法与分析框架 · v5.0

本文件服从 [Writing-DNA](Writing-DNA.md)。框架用来提出可核查的问题，不能先替所有人物写好动机或历史结局。

## 主张记录

每条重要主张记录以下内容，格式可沿用当前项目主张清单，不强制另造运行时schema：

| 字段 | 要回答的问题 |
| --- | --- |
| claim_id / 对应正文 | 这句话具体主张什么？在哪个版本、哪一段？ |
| 类型 | 是史籍记载、指控、现代解释、作者推论、艺术示意还是未知？ |
| 来源 | 书名、作者/编者、卷页/条目、版本、可访问链接、核查日期 |
| 原文与语境 | 哪一短摘支持它？上下文、说话者、时间和文类是什么？ |
| 依赖与反证 | 来源是否互相抄录？有没有不同记载或能推翻解释的证据？ |
| 结论边界 | 允许怎么说？哪些词必须保留限定？哪些还未查？ |
| 视听限制 | 能画什么？哪些动作、心理、音效会把推测变成确定现场？ |
| 核查状态 | 未核查、已核对受检记载、存在争议等；没有自动批准 |

数字需单位、时间、地域、统计口径。户数不是人口，登记数不是实际总数；不同年代数据不能无说明直接比。地图也有时间、范围与依据，控制区、影响区和争议区要分开。

## 来源如何使用

正史、编年史、实录、会要、碑志、笔记、诗文、考古与现代研究各有优势和限制。不要把所有笔记称第一手，也不要把史评、列传叙事和当事人原话混用。先核作者/编者、成书背景、材料来源、版本和文体。

诗文先核作者、作年、对象和文体。可以作为情境线索，与其他材料合看；不能直接证明作者当时的全部心理，更不能从一句诗推断杀人动机。

原文引语逐字核对，转录异文需记录。口语翻译用间接引语，并保留称谓、人物、时间、否定和条件。书中未说不等于实际未发生；也不能因为后果符合某人的利益，就反推他事先策划了全部过程。

## 分析模型作为问题

| 观察角度 | 可检验问题 | 需要防止的跳跃 |
| --- | --- | --- |
| 权力分工 | 哪些决策权、军队和任免实际由谁掌握？何时改变？ | 两个中心必然流血；官名即实际控制力 |
| 利益与约束 | 谁付钱、承担风险、得到职位？是否存在替代行动？ | 所有道德表达都是伪装；从结果直接读心 |
| 制度与个体 | 规则如何限制行为？哪些人走了不同道路？ | 把全部失败归罪一人/一派；把人写成制度木偶 |
| 叙事与记忆 | 谁记录、为何如此记录？其他版本如何说？ | 胜利者史书全部不可信，反向材料自动真实 |
| 秩序与生活 | 哪些群体在什么时期改善或受损？ | 用一个全国标签覆盖不同地区、阶层和年份 |
| 政治先例 | 后人是否明确援引先例？行动机制有何变化？ | 一次政变自动导致此后两百年所有政变 |

每个分析至少说明支持材料、一个可竞争解释和证据不足处。不得用热力学词汇宣告王朝宿命，也不把现代公司治理概念当成古代制度的同义词。可以讨论人的恐惧、信念与利害，但其证据强弱必须可见。

## 面向写稿的证据包

口语化改写必须继承主张ID、争议和不可拍边界。可以不用术语，不能不用证据。改写后回查人名、官名、年代、死因、数字、直接引语、全称判断和从结果推回动机的句子。

语料库用于观察语言，不能顶替来源。现有三组纠错示范是有限范围的核查演示，不能给整集、同系列或原作者作品背书。
