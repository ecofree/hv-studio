# 风趣历史 · Writing-DNA v5.0

生效日期：2026-10-19。入口与资产状态见 [README](README.md)。本文件是本目录唯一总规范；四份专项规范须遵守本文件，旧版规则与历史范例不再覆盖它。

## 1. 核心风格与优先级

像一位见多识广、讲得明白的说书人：用日常话解释兵粮、官位、亲缘、制度和选择的代价；让幽默来自情境，让人物保留复杂性。观众不需要先懂官制，也不该被当成等待训导的人。

发生冲突时，优先级为：**证据边界 → 清楚好懂 → 具体场景 → 幽默与修辞**。写不出有依据的现场动作，可以讲关系、选择和后果；不补汗水、眼神、手势、天气、密室对白来满足戏剧要求。已画好的场景也不能反过来证明历史。

不要求笑哭比例、比喻递减比例、固定字数、固定集数、固定三连句、必然悲剧结尾。词频只帮助发现复读；“不是……而是……”等正常语法不是自动删稿依据。标题、首帧、旁白和结尾应回答同一个问题，不用确定性的定罪标题包装尚有争议的结论。

## 2. 史料与主张

每个关键事实、引语、数字、死因、动机论证都有可回查的 `claim_id`。主张记录至少包括：口播表述、来源书名/卷页或条目、版本和链接、必要短摘、核查日期、主张类型、争议/反证、允许的画面表达与核查状态。具体方法见 [写作视角与认知框架](写作视角与认知框架.md)。

必须区分：史籍记载、史籍指控、现代研究解释、作者推论、艺术示意、未知。史书写了某事，不等于该事已被独立证实；成书早晚、正史或笔记类别均不能单独给出真伪结论。诗文可作解释线索，不能一律当作内心动机的实证。

引号内原文逐字回查并注明出处；翻译/口语改述用间接引语，不把自己的大白话署到古人名下。多部史书不能拼成一条“共同原句”。缺乏记载不能直接写成“从未”“没有调查”；“最后一句”“所有人”“当天”一类强断言应单独检查。

语言示范使用 [语言DNA](语言DNA.md) 的三组短例，均注明原典与已有核查范围；不要从旧稿、清洗语料或竞品报告自动提取事实。

## 3. 故事与口播工作流

1. 写清本集的核心问题、观众已有认知、结束时应理解的一件事，选与材料相称的结构和时长。
2. 完成来源矩阵与关键主张记录。把未解决争议写进大纲和分镜限制，不在口语化改写时丢弃。
3. 执行**【强制两步门禁协议】**（不可跳过的核心生产门禁）：
   - **门禁一（写前锁死：原典与防脑补核查表）**：收到写稿任务时，严禁直接输出剧本正文！必须先按幕输出结构化核查表，包含：
     1. `原典原文短摘`：直接贴出本幕依据的文言原句（无原文支撑的情节直接砍掉）。
     2. `史源性质标注`：区分正史、门人传记（如《慈恩传》带宗教尊崇与感通色彩）、笔记等，正文中必须带出“据《XX》记载”等限定语。
     3. `数字与引语锁死`：本幕所有数字（人数、里程、容积、时辰、比例）必须与原典短摘逐字对应；口语改述一律用第三人称间接引语，严禁把现代大白话放进双引号 `“ ”` 或用冒号 `：` 编造第一人称台词（如“寡人……”、“朕……”）。
     4. `本幕处境拧巴点`：用一句话点明本幕“谁被什么制度规矩、物理绝境或人情两难卡住了脖子”，以此作为戏剧张力来源。
   - **门禁二（写后剃刀：三刀物理自检）**：每幕正文生成后，必须执行三次物理级删改：
     - **第一刀（剃生理脑补）**：检索“耳光、颤抖、汗水、眼泪、起泡、焦黑、眼神、拳头”等词，凡上方【原典原文短摘】无对应字眼的，全部删改，改用原典真细节（如老马“忽异路，制之不回”）。
     - **第二刀（剃伪造对白与错引）**：核查所有双引号与冒号，非逐字文言原文一律去引号改间接转述。
     - **第三刀（剃幕尾AI升华）**：检查每幕最后两句及全篇结尾，凡出现“不是A而是B”对称金句、“在历史上刻下不可磨灭的印记”等抽象拔高，直接整句砍掉，让结尾停在具体的历史事实、数字或遗物（如“一领粗竹席”）上。
4. 每幕交付“新证据/新信息 → 人物可选行动 → 实际选择 → 后果 → 下一个问题”。没有信息增量的场景应合并或重写，不靠气氛拖长。
5. 做说书口吻改写：去抽象空话、解释必要官名、减少代词歧义，保留原主张ID和不确定性；不要求另开代理或丢掉证据上下文。
6. 逐句回查事实和引文；对照大纲核对因果、时间、人物、数字，再进行自然速度试读。
7. 形成一个可审阅的新正文版本和前后diff。现有授权范围内继续修订；事实/艺术/发布状态由实际审阅记录决定，不能自动填写“已批准”。

多集专题按问题和材料分集。三部曲、八集只可作为项目选择，不能预先安排所有人物必经崛起、黑化、宿命灭亡。时长由当前旁白音色的实际读速与停顿测量，不承诺固定汉字数等于固定分钟数。

## 4. 正文、TTS、导演信息的交接

**唯一正文**：生产选择的明确版本和哈希是内容权威。TTS专版只能由该正文派生，输出正文到TTS的字符映射或等价可回查关系；不得维护另一份可随意删改的“同一稿”。字幕回到同一正文。实质删改必须产生新版本及可读diff。

**发音**：专名的标准字形保留。v2 `spoken_text.compile_text` 只允许标点处理，不引入 legacy 多音字替换。不把“右仆射”改成“右仆夜”来影响发音；发音需求进入独立说明，按引擎真实能力处理。同一音色控制不支持时如实标为待处理，不能静默换说话人。

**导演信息**：画面、语气、音效和停顿独立于口播正文，交接时必须保留原标注、归属句/字符锚点、类型、处理结果。区分已编译、仅保留供人工处理、无法解析。未知标注不可静默删除，也不可未经确认混入旁白。具体序列化格式以当前 parser/交接清单为准，本文不另造第二套运行时字段。

**声音表演**：说明说给谁、句子的意图、重词、语速趋势、停顿和强弱；不只堆“字字如刀”。先保留旧录音、选take和短段编辑；新调用须遵守项目持久预算。块大小由引擎限制、句义和实际试读决定，不用固定450–650/600–850字保证质量。

**画面**：固定画风、人物和音色继续沿用。图像提示只写主体、行动、环境、道具和光；画风唯一权威为 `profile.image.style_suffix` 与 `negative_clause`。禁止在单集提示中写风格词改变画风，禁止要求模型直接在底图绘制文字。

## 5. 验收与保留

- 内容：关键主张可回查；引语原样；争议传递到标题、画面和字幕；每幕回答核心问题的一部分。
- 交接：正文、TTS和字幕可对齐同一输入；导演标注有逐条去向；换稿后旧音频/图像/时间轴不会冒充新稿证据。
- 视听：按 [视觉风格指南](视觉风格指南.md) 做逐幕设计，完整试听看审，记录问题时间点和归属工序。不得将测试通过称为艺术批准。
- 保留：旧稿、原录音、已批准素材、图像缓存均保留；新版本独立交付。清洗库原字节不变，清理和去重有范围、原因和哈希。
- 技术：运行项目所需检查并保留当前源码与输入绑定证据。技术候选、事实复核、艺术判断和发布决定分别记录。

## 6. 本版取代的规则

| 旧要求 | v5处理 |
| --- | --- |
| 生死场面强制添加生理动作 | 仅使用可追溯动作；无据细节不写成口播事实 |
| 80%笑/20%哭、70/20/10语温、第四幕比喻清零 | 按叙事目的选择语气；没有比例硬门槛 |
| 双权力中心必然流血、王朝注定崩塌 | 分析为可反证的假设，检查其他解释和实际选择 |
| 诗词一律证明心理 | 核文体、作者、作年和对象，区分文艺表达与事实 |
| 固定八集、固定字数TTS安全块 | 按材料、引擎和实测规划 |
| 旧脚本为官方标杆、语料全部已分析 | 资产分级；历史版本待审，清洗正文全部未核史实 |
| 说书阶段卸载证据约束 | 可改口吻，必须继承主张、争议和不可拍边界 |
