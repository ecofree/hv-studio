# 故事结构选择 · v5.1

本文件服从 [Writing-DNA](Writing-DNA.md)。结构由问题和证据决定；以下是选项，不是每集必须套用的流程。

## 先交付一页提纲

写清核心问题、已有认知、最需要纠正的误解、答案边界、材料能支持的长度。每幕填写：新信息、相关主张ID、人物目标、可选行动、实际选择、后果、观众此刻应明白什么、下一个问题。若材料不能回答，就缩题或明确未知，不用低沉气氛填补。

提纲与分幕写稿时，除核对‘新信息 → 可选行动 → 实际选择 → 后果’的证据链外，必须标出本幕的**具体利害切口**（如名分与实权的落差、计划与实际后果的错位、或不同史料记载之间的张力），并放大原典中1～2个反常真细节，杜绝用俗套影视动作替代原典。

## 常规长视频（15–25分钟 / 3,500–5,500字）宏观牵引引擎

制作常规长视频（15–25分钟 / 3,500–5,500字）时，除单幕微循环外，提纲阶段必须强制设计以下四项跨幕结构，防止中盘疲软与注意力下滑：

1. **立住“全片倒计时时钟”（Master Clock）**

   * 开篇 60 秒内，必须把一个**不可逆的物理或时间死线**拍在观众面前（例如：大军断粮只剩 12 天、距离宫变发作只剩 48 小时、朝廷规定的平叛死限还剩三个月、保卫关中仅剩 25 个月倒计时）。
   * 每当一幕结束、切换下一幕时，旁白用一句话明确拨动时钟（如“距离最后期限，只剩下不到一半的时间”），让全片始终处在紧迫的倒计时张力下。
2. **强制“宏观与微观的变焦切换”（Zoom-in / Zoom-out）**

   * 严禁连续三幕都在写朝堂博弈、兵力调动或制度推演（高密度宏观信息会导致观众大脑过载产生疲劳）。
   * **变焦铁律**：连续两幕写大局（宏观）后，下一幕必须切入一个**极小的微观切口**——一笔具体的粮草运费折算、一封有据可查的家书、或者一个边缘小人物在制度夹缝里的具体算账。用具体的人情和物理细节给观众“换气”，情绪温度正是在这种切换中建立起来的。
3. **埋设“跨幕伏笔”（Open Loops，严守原典边界）**

   * 在第 1–2 幕看似顺带交代环境或制度时，刻意点出一个**有原典依据的物件、一条冷门律法、或一个当时不起眼的低品级官员**（如早期经商的胡人家族、某位手握钥匙的禁军将领）。
   * 不做多余解释，直到第 4–5 幕主角陷入绝境或局势反转时，再把这枚伏笔重新拎出来引爆，制造长视频独有的“草蛇灰线”爽感。
4. **设计“50% 中盘局势变异”（Mid-point Escalation）**

   * 长视频最忌讳前半段讲完核心矛盾、后半段变成流水账式的收尾。
   * 在全片 50% 进度处，必须安排一次**局势性质的突变**（例如：原本的敌人解决了，但更大的危机来自内部；或者原以为是必胜的奇袭，突然变成了断绝后路的死守），逼迫人物推翻前半段的所有算计，重新开局。

## 超长篇（35–45分钟 / 8,500–10,000字）扩容规范

当单集目标时长超过 30 分钟时，严禁通过拉长单幕字数凑时长（单幕仍死守 500–600 字，每 100 字必须对应至少 1 条独立历史事实原子）。必须通过以下四项结构扩容：
1. **“3–4 大篇章 × 14–18 分幕”两级嵌套**：每 4–5 幕收拢为一个大篇章（约 10–12 分钟），每个篇章必须设立独立的阶段性死局与结算点，每 10 分钟兑现一次阶段性高潮（注意：大篇章标题仅作结构划分，严禁在口播正文中念出“第X大篇章在此完成结算”）。
2. **A/B 双线交替推进**：提纲阶段必须设计两条交织叙事线（如前线战局与后方筹粮/朝堂博弈/敌国内讧），每 2–3 幕切换一次视角，防止长时段单一视角的听觉疲劳。
3. **防迷路轻量唤醒**：凡间隔超过 4 幕重新出场的非核心人物，再次登场时必须顺手带出一个 4–6 字的身份回忆标签（如“当年在洛阳管粮草的某某”）。
4. **题材配重均衡**：多势力并行题材（如西秦与河西双线），各核心势力篇幅需保持合理配重，严禁出现前 14 幕写一方、最后 2 幕草草收尾的“头重脚轻”结构。

## 可选结构

|题材目的|推进方法|避免|
|-|-|-|
|人物抉择|处境 → 可选道路 → 行动 → 代价 → 回看选择|先给人物定好忠奸，再找行为填空|
|史料调查|矛盾说法 → 来源位置和语境 → 互证/反证 → 能确认的边界|把悬案标题写成定罪；只按书写早晚定真伪|
|制度解释|具体难题 → 制度怎样运作 → 谁受影响 → 例外/成本 → 变化|没有实例的抽象术语；把制度必然写成阴谋|
|战争地理|目标 → 地形与补给约束 → 选择与行动 → 结果 → 解释限度|无来源战损比、现代边界冒充古代控制区|
|旅行见闻/生活史|一个具体问题 → 空间或物件线索 → 不同人经历 → 新认识|把一个笔记故事推广为整个时代日常|
|传闻与文学接受|明说文本性质 → 故事怎样流传 → 各版本差异 → 文化意义|把小说桥段当实录|

## 首帧、每幕与结尾

首帧提出本集实际会回答的问题，避免靠未证实罪名制造冲击。开场尽早给出人、事、约束或来源矛盾；可自然设问，不机械禁止某种句式。

每幕让一个关系、认识或处境发生变化。争执、兵变之外，解开一个官名、看懂一条路线、发现一句引文被误用，也能构成有效推进。图表、停顿、空场只在帮助理解时使用。

结尾兑现开场承诺，区分事实结果与解释。可以收在遗憾、欣喜、惊讶、仍然存在的问题；不强制前笑后哭、英雄升华或命定衰亡。不为了下一集悬念隐瞒本集必要答案。

## 多集与时长

先划问题边界，再决定单集或系列；三集和八集均不是硬规则。每集能独立说明一个问题，接续处记录已知人物、时间和未解决线索，减少重复铺垫。

长度依据当前音色的试读、信息密度与停顿估算。TTS分块遵循实际引擎能力和句义，不能用固定字数保证不漂移。若超长，先削重复解释或拆清问题，不靠加速旁白挤时间。

验收时让不熟悉该段历史的试看片者复述：发生了什么、为什么、哪些仍不确定。记录其卡住的具体句子/时间点；没有实测数据就不宣称模板提高完播率。
