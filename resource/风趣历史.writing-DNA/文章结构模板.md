# 故事结构选择 · v5.0

本文件服从 [Writing-DNA](Writing-DNA.md)。结构由问题和证据决定；以下是选项，不是每集必须套用的流程。

## 先交付一页提纲

写清核心问题、已有认知、最需要纠正的误解、答案边界、材料能支持的长度。每幕填写：新信息、相关主张ID、人物目标、可选行动、实际选择、后果、观众此刻应明白什么、下一个问题。若材料不能回答，就缩题或明确未知，不用低沉气氛填补。

提纲与分幕写稿时，除核对‘新信息 → 可选行动 → 实际选择 → 后果’的证据链外，必须标出本幕的**具体利害切口**（如名分与实权的落差、计划与实际后果的错位、或不同史料记载之间的张力），并放大原典中1～2个反常真细节，杜绝用俗套影视动作替代原典。

## 可选结构

| 题材目的 | 推进方法 | 避免 |
| --- | --- | --- |
| 人物抉择 | 处境 → 可选道路 → 行动 → 代价 → 回看选择 | 先给人物定好忠奸，再找行为填空 |
| 史料调查 | 矛盾说法 → 来源位置和语境 → 互证/反证 → 能确认的边界 | 把悬案标题写成定罪；只按书写早晚定真伪 |
| 制度解释 | 具体难题 → 制度怎样运作 → 谁受影响 → 例外/成本 → 变化 | 没有实例的抽象术语；把制度必然写成阴谋 |
| 战争地理 | 目标 → 地形与补给约束 → 选择与行动 → 结果 → 解释限度 | 无来源战损比、现代边界冒充古代控制区 |
| 旅行见闻/生活史 | 一个具体问题 → 空间或物件线索 → 不同人经历 → 新认识 | 把一个笔记故事推广为整个时代日常 |
| 传闻与文学接受 | 明说文本性质 → 故事怎样流传 → 各版本差异 → 文化意义 | 把小说桥段当实录 |

## 首帧、每幕与结尾

首帧提出本集实际会回答的问题，避免靠未证实罪名制造冲击。开场尽早给出人、事、约束或来源矛盾；可自然设问，不机械禁止某种句式。

每幕让一个关系、认识或处境发生变化。争执、兵变之外，解开一个官名、看懂一条路线、发现一句引文被误用，也能构成有效推进。图表、停顿、空场只在帮助理解时使用。

结尾兑现开场承诺，区分事实结果与解释。可以收在遗憾、欣喜、惊讶、仍然存在的问题；不强制前笑后哭、英雄升华或命定衰亡。不为了下一集悬念隐瞒本集必要答案。

## 多集与时长

先划问题边界，再决定单集或系列；三集和八集均不是硬规则。每集能独立说明一个问题，接续处记录已知人物、时间和未解决线索，减少重复铺垫。

长度依据当前音色的试读、信息密度与停顿估算。TTS分块遵循实际引擎能力和句义，不能用固定字数保证不漂移。若超长，先削重复解释或拆清问题，不靠加速旁白挤时间。

验收时让不熟悉该段历史的试看片者复述：发生了什么、为什么、哪些仍不确定。记录其卡住的具体句子/时间点；没有实测数据就不宣称模板提高完播率。
