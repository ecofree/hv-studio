# 猫样美男李义府（上）

显庆元年（公元656年）某日早朝，御史王义方毅然出班弹劾中书侍郎李义府，称他擅杀大理寺监狱六品寺丞毕正义，理应治罪。

这案子大概是这么回事：

有个洛州女子淳于氏，因为作奸犯科被关入大理寺监狱，还涉嫌大案要案。朝中红人、中书侍郎李义府听说这姑娘貌美如花，仗着自己官高得势，暗中指使大理丞毕正义把她放出来，然后收回家当了小老婆。

私纵戴罪之人可不能算小事儿，瞒不住的，于是大理寺卿段宝玄只好据实上奏。唐高宗李治听完即刻命人审理，李义府担心事情败露，竟然逼着毕正义在办公室上吊以断绝实证。

就是这么档子事情，闹得一时间朝野哗然。唐高宗虽然查得了实情，但却存私心没有追究李义府的罪责。

所以，这次王义方就此事弹劾李义府，唐高宗本也不想追究，但一拿到王义方的奏章就被深深吸引了，反复看了好几遍——写得很有料，指李义府当初凭着长得不错，被俩男领导搞过“双龙入洞”才上位的，语言还特别写实细腻：

刘洎邪魅一笑，用脖子以下的不能描写的部位分开李义府的脖子以下的不能描写的部位。李义府颤抖着摇头：“不不，使不得……” 刘洎哪里会听，故意用脖子以下的不能描写的部位磨蹭着李义府脖子以下的不能描写的部位，边将嘴唇贴近他耳边：“嘴上说着不要，身体倒是很诚实嘛！你看，你的脖子以下的不能描写的部位已经这么不能描写了呢！” 李义府满面羞愧，无地自容，正要开口反驳，一直没有言语的马周却没有给他这个机会，狠狠挺身，脖子以下的不能描写的部位已经不能描写地不能描写进了李义府脖子以下的不能描写的部位，重重地不能描写了起来……

唐高宗读完这耽美向奏章，神魂颠倒不能自已，鼻息粗重之际脑间一个炸雷：快醒醒你他妈是异性恋饭在锅里媚娘在床上别入异端啊啊啊啊啊！！！！

于是唐高宗的半条大腿又缩回到柜里去了，怒斥王义方言辞猥亵，涉嫌诽谤。

退朝后，李义府不无得意地问王义方：“王御史你写得挺生动啊，是不是听墙根儿来着？我可屁事没有，你说你瞎告状就不觉得羞愧吗？”

王义方看都不看他：“是挺惭愧的，当年孔子当了七天鲁国司寇就诛杀了少正卯，我这御史当了六天，却除不了你这奸佞，我惭愧的就是不能宰了你！”

“狱女”事件就此告终，王义方被贬为莱州司户，李义府毫发未损，反而越来越得恩宠，擢升中书令、检校御史大夫、太子宾客、河间郡公，还分了套大面积精装房改房。

说了半天，这李义府啥来历，这么能嘚瑟呢？

他可真的不简单。“笑里藏刀”这个成语学过吧？形容阴险小人在人前和颜悦色，但实际上却是阴险毒辣。这个典故就出自于他。《旧唐书·李义府传》中称：义府貌状温恭，与人语必嬉怡微笑，而褊忌阴贼。既处要权，欲人附己，微忤意者，辄加倾陷。故时人言义府笑中有刀。又以柔而害物，称为人猫。

李义府，四川人，小门小户出身，先天优势有俩：一是聪明，二是靓仔。后来这两大优勢都用上了，一点没浪费。

李义府二十岁的时候，剑南巡查李大亮赏识他的才华文笔，推荐他到宫里当了门下省典仪。其后又逢机缘，得到当时权臣刘洎、马周（就是据传“双龙入洞”的两位耽美大神）的双推，才有了面君的机会。

偶然一次，李义府在唐太宗面前凭借打油诗才艺表演赢得了赏识，被火线提拔并派到晋王身边听差。

你知道的啦，后来晋王李治发育着发育着，就发育成了唐高宗李治。

高宗即位之后，作为嫡系部队的李义府官运享通，入弘文馆学士，改修《国史》。

当时正是高宗的舅舅长孙无忌大权在握，李义府不招他待见，就挑了个毛病上表把李义府贬为壁州司马。高宗有心想保，可连自己的皇位都是舅舅帮着争取来的，没啥话语权，所以不敢为李义府多说话。

敕书尚未正式下达，李义府就从小道获知了消息。地方官远离权力中心，跟自己勇攀高枝的远大理想南辕北辙啊，所以他心急如焚，赶紧找好兄弟王德俭商量对策。

王德俭是权臣许敬宗的外甥，跟他舅一样，极其擅长揣摩领导心思，就提点李义府说：现如今啊，皇上跟武昭仪俩人蜜里调油如胶似漆，早想离婚换她当老婆了，只苦于长孙无忌和褚遂良这俩糟老汉的阻挠，一直没敢实施。你立刻拿出态度来，支持废王立武，保你今后前途似锦，封侯拜相跟闹着玩儿似的。

听了这番金玉良言，李义府如醍醐灌顶，大半夜去敲高宗的门，上表请求废黜王皇后，改立武昭仪。文末还展望了ー下美好未来，说要是媚娘当了皇后，那ー定是“苍生仰其德，史册书其美”！高宗读得心旌摇曳，喘着粗气收回了贬官敕书，将李义府留居原职，还加了鸡腿。

关于废王立武，这里多说两句。

大家记住喽，一切后宫斗争的本质都是政治斗争，没有例外。

高宗换媳妇儿这事，绝逼不是那些个玛丽苏电视剧里演的啥“因为爱情”，而是唐高宗跟以舅舅长孙无忌为代表的关陇贵族军事集团之间残酷权力斗争的表象。

当初，长孙无忌之所以扶持李治而弃太宗本来看重的李泰，很大一部分原因就是李泰在朝中已有自己的班子成员，他怕上台后没法控制。相反，李治光杆司令一个，看起来又弱鸡，自己妥妥的“摄政王”。

毫无意外，高宗登基之后根本没话语权，朝廷重权几乎全落在以他舅舅为首的关陇集团手里，他自己也就能考虑一下晚上吃麻辣烫还是串串香。

所以，如果高宗想要掌握实权，关陇集团必须滚犊子。

拿谁开刀呢？当然是身边离得近的，老婆王皇后。

王皇后出身太原王氏，高祖父王思政是西魏的将领，母亲家则是李唐王室的旧亲，父母两族都属于关陇集团，可以说是关陇的亲亲亲闺女。

可能李治问过王皇后类似“我跟你爹一起掉进河里了你救谁”这么谜的问题，而王皇后的回答大概率是救爹，救完爹连工资卡都要放在娘家给爹补身体。所以高宗还能说啥？这婚必须得离，跟爱情不爱情的真没啥关系。

高宗最开始拿来当枪使的是出身兰陵萧氏的萧淑妃，怎奈这婆娘胸大无脑中看不中用，所以高宗只好把没出身没势力没钱的媚娘拉出来跟根正苗红的王皇后死磕。呐，高宗口口声声说“只是自己私事”你就呵呵呵吧，李唐王朝的政治斗争真是最高水平，辫子戏的还珠格格九龙夺嫡啥的看看热闹得了。

长孙无忌满以为这软趴趴的外甥是一时色迷心窍，不敢干什么出格的事儿，还能真离？

可惜他看走眼了。

太宗与长孙无忌都曾认为李治仁懦，后来欧阳修在《新唐书》里吐槽这二位其实都没认清李治。

李治这个人嘛，若要概括，大概是闷骚、鸡贼、外柔内刚、大隐于无形、懂得闷声发大财，不爱热闹不蹭热点：小时候面对一个杀兄逼父的父皇、几个斗得昏天暗地的哥哥，装傻充愣，表现出不问天下事只读圣贤书的样子，最后皇位到手；青春期敢在父皇还活着时跟小后妈私通，登基了把小后妈明目张胆整到身边，还想娶来当老婆。

所以哪里仁懦了？就因为他眼泪多？扮猪吃老虎了解一下。

其实论起在高宗面前的醒目程度，谁都不如媚娘。

不少人因为媚娘二十来年的太后+天子生涯误会高宗柔弱。最扯的武媚娘传奇，高宗在的时候就自称武则天。如果高宗看自己的皇后有如此惊天动地气壮山河的想法，陪葬都嫌太慢，第一时间直接赐死拉倒。

事实上，史书中处处可见的是媚娘一心讨好着老公，小心揣摩老公的心思。人家懂事，清楚自己的立场，清楚自己执政的一切权力都来自于老公，清楚自己是老公的门面、打手、CEO，背锅侠，清楚李治哎呦哎呦地养他的风眩病，但掌握着大权。

因为清楚，所以知心，所以般配。

那么当政治家一脸“都怪老婆太凶呀我其实是好孩子嘤嘤嘤”的时候，你可别幼稚，不是一家人不上一个炕。

长孙无忌的走眼，在于他不清楚。他不清楚自己的权力一直都是来源于高宗，他错把这个权力当成了自己的东西，这点他还真不如媚娘。

所以直到自己的阵营崩溃，自己走投无路唯有上吊那一刻，他才知道自己的权力有多脆弱，大外甥要办他和他身后的人，只需要边哭边写一纸薄薄的诏书而已。

这题跑得实在太远了。

等我想想怎么圆回来……
