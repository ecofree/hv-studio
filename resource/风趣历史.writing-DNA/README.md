## 资产可信等级

- `raw/` 是原始抓取，保留原字节和来源；包含小说讨论、传闻、推广和网页残留，不能整体称为“103篇已核验的历史长文”。
- `_meta/` 是旧分析结果，原样保留作追溯。统一的题材/史料/结构标签不代表逐篇验证，不进入新清单。
- `curated/texts/` 是去网页污染和重复权重的语言观察库，**不是史实依据或自动认可的示范库**；逐篇内容评估未完成。只按当前写作问题挑短段，不能将全文直接改头换面为新稿。
- `scripts/` 下既有文案、TTS专版、音频和生成脚本均为**待审核的历史版本**。保留旧文件以便对比，不再称“官方标杆”，不自动导入生产。若其中出现新修订稿，以该稿显式版本、主张核查记录与交接清单为准，不能从文件名推定批准。
- `风趣历史风格与内容深度审计及顶流竞品研究报告.md` 为**待复核研究参考**。缺乏来源、采样日期、统计方法的播放/粉丝/比例/平台结论不作为事实、预算或选题依据。
- 旧规则快照保留在项目 `state/content-refactor-20261019/before/`，仅用于前后对比。它不是并列有效规范。

当前安装的 `fun-history-writing-dna/SKILL.md` 已同步为引用本目录的入口，旧入口备份在 `state/content-refactor-20261019/before/installed-writing-skill.md`。其他机器如仍安装 4.5，应先进入本目录读取 v5；不能仅加载旧 Skill 而跳过当前项目规范。

## 制作边界

项目 `AGENTS.md` 与当前生产实现继续约束制作：固定画风由 profile 的 `image.style_suffix` 和 `negative_clause` 控制；沿用现有人物、旁白音色和旧素材。整理语料不会授权替换音色、重绘素材或调用提供商。正文是内容权威，TTS是其派生文本，导演信息单独交接并显式记录处理状态；不把同音错字写回正文或字幕。

统计和清洗方法见 [curated/README.md](curated/README.md)。在项目根目录运行 `bin/curate_writing_dna.py --check` 可验证清单与正文能由原始输入重建；此检查不授予史实、艺术或发布批准。
