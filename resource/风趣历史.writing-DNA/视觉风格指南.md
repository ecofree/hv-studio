# 视频视听交接指南 · v5.0

本文件服从 [Writing-DNA](Writing-DNA.md)。保留现有画风、人物、旁白音色和旧素材。画风唯一权威是项目 profile 的 `image.style_suffix` 与 `negative_clause`；本文件不指定替代风格，不以影视截图/表情包比例改写项目视觉语言。

## 每幕设计表

每幕至少说明：对应正文版本/段落/主张ID、观众要理解的新信息、时间地点、出场角色ID与年龄阶段、镜头目的、需要的证据或示意、声学锚点、动静变化、停留理由和待处理项。现有画面可以继续使用，但须核对它会不会比旁白更确定。

| 叙事需要 | 可用画面 | 边界 |
| --- | --- | --- |
| 认识人物关系 | 角色位置、称谓和关系连线分步显现 | 身份、时期、关系有依据；不暗示无据密约 |
| 理解制度或选择 | 官职功能卡、时间线、选项与结果 | 标明解释层，不能把现代比喻当古制实物 |
| 比较争议 | 并列史料卡、书名卷次与必要短摘 | 保留来源差异，不用确定行凶画面盖过争议 |
| 理解战争/行程 | 地形、路线、时序分段显现 | 地名与边界绑定时期和来源，示意范围有标识 |
| 感受处境 | 现有角色、空场、低强度环境动画、适时停住 | 无据心理、动作和处刑细节不作事实特写 |

图像提示只描述人物、行动、地点、道具、光线，不加入改画风词，不让模型在底图生成文字；标题、字幕、史料卡交由叠加层。服饰器物和身份需有参考，不能因为底图漂亮就跳过时期检查。

## 连续性与动画

角色ID、年龄、衣着主特征、站位、视线与出入方向应保持可追踪。局部环境动效和2.5D视差先明确前/中/后景、移动范围、保护区域和遮挡边界。现有实现不生成遮挡后的未知背景、不驱动人物口型或动作；不要在设计表中把它标成已实现的人物动画。

雨、光与视差服务本幕目的；人物、手、脸和字幕区域保护。强度随信息和语气变化，可以停住。长镜头先问信息是否推进，不机械套用每几秒切图或 legacy 帧数上限。多个镜头使用同一画面时要检查共享时钟和切点是否跳变。

## 声音与导演信息

表演要求写为：说给谁、想让观众理解什么、重词、速度趋势、停顿、强度。原旁白音色保持；用现有take选择、短段编辑、停顿与声效退让改善表现。增益、氛围声不等于TTS新增情绪控制；不支持的指令标记待处理，不能静默换音色。

每条导演标注保留原文、类型、正文锚点和处理状态。画面/语气/音效不能被当正文读出；停顿不能只因换了英文标记就失效。以当前parser的交接报告核对哪些已执行、哪些仅保留、哪些无法解析，再进入合成。

字幕使用唯一正文标准字形；字幕几何、安全区和标题避让按当前实际分辨率验证。对齐核查包括句义、读音、停顿、画面信息出现时点，不能只比较总时长。新增音频或提供商调用仍遵守项目预算要求。

## 完整看审

记录时间点和具体问题：人物是否认得、时地是否清楚、画面是否替争议定案、字幕是否可读、声效是否抢词、重复底图是否仍有信息推进。技术校验、史实核查、试听和艺术判断分别记录；接触表不代替正常速度完整观看。

## 附录：文章渠道排版

公众号或图文导出版可按手机阅读拆段、加小标题和图注，但没有单句段比例、三行上限或配图比例硬要求。图注要说明来源与图意，不强制图前引线、图后补刀。图文排版不得改变视频正文与导演标注的归属。
