# 唐代著名诗人杀人事件

- **作者**: 历史第一狗仔队 (honghuidian1230)
- **发布日期**: 2018
- **原文链接**: https://mp.weixin.qq.com/s/08AIEZvJ59EGTqzoXIyQXg

---

盛唐时期的诗人们，内心都有点古惑仔情结，他们的理想生活状态是：骑宝马来佩宝刀，夹着小包喝小烧，闲来无事真烦恼，下场砍人解心焦。

凡是胸中有点丘壑的中二青年，乐意没事凑在一起喝大酒、打嘴炮。有人起个头：杀人如翦草，剧孟同游遨。对面的就不服：杀人辽水上，走马渔阳归。旁边的紧跟：义士频报雠，杀人不曾缺。最后墙角坐着的也憋出来：杀人红尘里，报答在斯须（向李白、崔颢、王昌龄、杜甫几位大佬致敬）。

捕快：诶诶诶，内一小撮儿男青年，对，说你们呢，杯放下，杀人的事给我交代清楚！

青年：同志，其实我们连鸡都不敢杀。

捕快：那你们刚才瞎78 freestyle个啥？

青年：哎，那没事总说“日了狗了”的人，不也没真日嘛！

捕快：那不好说，也有豁得出去的。

青年：……毕竟……少。同志，您看，我们也就是没事装装逼败败火，您别逮着我们几只蛤蟆非要挤出脑白金来了，您真想抓干坏事的，我们跟您举报一个，给您这个月添点绩效，怎么样？

捕快：有黑恶势力作祟要主动跟政府反映！

青年：是是是。有个叫宋之问，身上有事儿。

捕快：他肿么地了？

青年：据说他为了抢一首诗，杀了他外甥刘希夷。

捕快：卧槽恶性案件！有证据吗？

青年：那倒没有，路透社消息。太多的我们就不清楚了，您自个儿调查吧。

捕快：那你们认识到自己的错误没有？

青年：认识到了认识到了。我们自由散漫，无所事事，羡慕资产阶级和无政府主义的生活方式，客观上起了破坏安定团结的社会局面的作用，亲者痛仇者快，也辜负了政府对我们的殷切期望。我们决心吸取教训，痛改前非，立大志，吃大苦，开创自己生活的新局面，做个无愧于伟大时代的新青年，请领导和同志看我们的实际行动吧！

捕快：嘴忒贫，赶紧走，再有不恰当言论还把你们逮回来。

以下，是捕快同志的走访调查笔录：

1、宋之问邻居王大妈：

你问宋家老大？哎呦我们家跟他们家可有两辈子人做邻居了，眼见他哥仨长大的。别看他们爹宋令文那损样，当初追我我都没同意，孩子倒是一水儿的有出息。尤其这宋家老大，不到二十考上公务员，专门给领导写材料。人家材料写得好，提拔特别快。我当初就看好这后生，本打算说和着，让他做我们家女婿，但是我这闺女，虽说出生在我们这劳动人民的家庭里，可打小就资产阶级思想严重，刚学走路就嗖嗖往那小资产阶级腐朽情趣的道上迈，就喜欢那些个长得帅啊会乐器啊能说会道的男孩儿，还非说人家宋老大有口臭，死活不同意。我真是……啥也不说了。

啊，对，他是有个外甥，姓刘，他爹入赘老宋家，没几年就病死了。这小孩从小住在他姥爷家，跟三个娘舅一起学习什么的，快20了才搬回他爹老家去。其实要不是你特意问了，我都不想提，唉，我女儿当时就是看中了这小子，才死活瞧不上人家宋老大。这小子虽然长得帅，文化程度也不差，还能弹琵琶唱曲儿，但他不正经过日子啊，不当官，不上班，不赚钱，成天就溜达，写诗。我可不想让我闺女落到这号浪催手里，过个一年半载抱回个瘦成皮包骨的外孙子，奶粉钱还得我出，你说我闹心不闹心？我还指望我们闺女将来嫁个高干子弟，咱也坐坐小汽车，看看内部片儿什么的。诶捕快同志，你多大年纪了？爹妈干啥的？有房有车不？婚配没有？

2、宋之问的崇文馆同事杨炯：

实话实说？行。宋之问利欲熏心卖身求荣骑墙劈腿恩将仇报真的不要脸！

一个大老爷们儿，成天卯足劲往女领导床上爬，我们文联都替他丢人！败坏风气！咱诗人的社会责任感都哪儿去了？让外人怎么看咱文艺圈？好，退一步讲，你爬就私下爬呗，还写出来辣大家眼睛，什么什么“明河可望不可亲，愿得乘槎一问津”，真不知道寒碜。一些个狐朋狗友，崔融之流，还使劲给他拉皮条，真是鱼找鱼，虾找虾，乌龟专找大王八。关键是，费了这么大劲，领导死看不上他啊，说他有口臭哈哈哈哈哈嗝。要是我上，可能领导各方面都能挺满意——当然了，我绝不可能干这事儿，原因有二：一方面，武皇七十来岁，一摸跟老丝瓜似的，我提不起性趣；另一方面，我妻子近年来趋于亢进，我抖擞精神全神贯注尚不能旗鼓相当，哪会余兴他顾？

好，不说我不说我，说宋之问。后来他看伺候武皇没戏，就去伺候武皇的姘头，天天给小白脸张易之当枪手、端尿盆，比伺候他爹都到位。可那又怎么地？武皇一退休，张易之就被枪毙了，你宋之问还不是流放广东？同志，你们别看他“近乡情更怯，不敢问来人”搁那装鹌鹑，为啥到了家门口不敢跟人打招呼？那他妈是因为流放期间他私自跑回来，一个流窜犯敢在大街上打招呼？政府把他脑袋削放屁！跑回来以后人家王同皎冒险收留他，他找个由头就举报老王，搞得人家家破人亡，他自己举报有功，重新当了官，乐得嘴咧到耳后根。

所以，捕快同志，像宋之问这么没底线的人，你说他因为抢诗杀他外甥，完全有可能！恳请你们秉公执法，直接逮捕，逮捕以后直接枪毙，苦口婆心不如手枪一响，对烂到根子里的坏分子就得见真招，就得执法无情。我还不是说，要让我去刑部，准能让咱国家没一个敢违法乱纪的。好好好，不说我不说我，不说我那我就没什么可说的了。

3、宋之问的好友崔融：

我承认，老宋是我介绍给武皇的，这事儿，是一个想买、一个愿卖，我就想学雷锋做好事两边成全，连中介费都没收，杨炯这傻逼骂我干啥？

另外，给领导端尿盆怎么了？怎么就没底线了？你刚参加工作不得给领导端个茶倒个水的吗？端茶杯和端尿盆有什么本质上的区别？年轻人，多做一点，就多成功一点，每一个成功的背后，都有辛苦的付出啊。杨炯这傻逼，这么多年爬不上去，还不是因为端着装清高？哼！

至于老宋有没有抢诗杀人，我不清楚，但老宋的性格有缺陷，不像我多少有点克制力，他是一见喜欢的就没命，决不肯中途收兵。从平时和他吃饭、打麻将就可以看出来，暴饮暴食，只和大的。这脾气，引导得好，可以是股改天换地的力量，搞不好，就会是个很大的危险啊！

4、宋之问本人：

首先，骂我的，通通反弹！

说我嫉妒刘希夷？明明是我更红好伐？满大街的人排着队嫉妒我好伐？我嫉妒他？他给我扛大腿提鞋都不配。好了，现在我官宣一下真相：刘希夷是自杀，对，自杀！

大家都知道，国家宣传部秘书不好当，今天求雨，明天登月，后天港珠澳大桥开通，我们部门就得绞尽脑汁，顺应时代，各种彩虹屁。写得没水平还不行，像王兆山之流，又是“主席唤、总理呼”，又是“纵做鬼，也幸福”的，不说自己挨不挨板子，连儿子在学校都是要被同学满操场追着打的！太费脑子啊！你看我，这么英俊，可惜谢顶了，临场发挥也弄不灵光，只能平时遇到妙句记下来，灵活运用。

有一天，刘希夷带着他新写的《代悲白头翁》到我家来，我一看，哎呦，那句“年年岁岁花相似，岁岁年年人不同”太他妈牛逼了，领导一定能喜欢！他一个白丁，这诗在他手里那就是明珠暗投，我就跟他商量把这首诗让给我，物尽其用。

劝了好久，他勉强同意，我也没亏他，又送他笔又送他桌，还送他一个大黑铁锅。第二天我把诗改了改，换名《有所思》，递上去了，武皇给了我一个秋波，甜。

结果没几天，这刘希夷王八羔子说他后悔了，想把诗要回来！妈卖批哦，那我不是欺君之罪？我想着，还是得跟他好好说说，阐明利害呀，就把他留下喝酒。喝到后半夜他醉了，我扶他去睡，怕他半夜脚冷，就在他脚边放了一个装土的袋子，告诉他半夜压压脚。结果早上一看，丫方向感太差，袋子压在脸上！拿起袋子，他已经没气了。

你看，人死在我家，丧葬费我出，这理所当然，我没二话。可我出钱也没落好！文联的朋友都说我杀了他，一天啐我三顿，说我不要脸。朝廷这边，太平公主说我贪污受贿，官给我免了，朝也不让我上了，皇上一天到晚拿我当反面例子教育其他同事，我这么活着有什么劲？要不你们直接把我判了吧，监狱的日子也比现在好过。

以上是所有笔录内容。

捕快同志分析来了解去，这案子还没等研究明白，宋之问被赐死了，专案组就地解散。

从此，此事就成了无头公案。但《全唐诗》暗戳戳地把宋之问的《有所思》和刘希夷的《代悲白头翁》全收录了，两诗只有三个字不同。且《全唐诗》在介绍刘希夷时，说他“为奸人所杀”，还神补刀：“或云，宋之问害希夷”。

要了命了。

还有更要命的，就是《唐才子传》，非常肯定刘希夷就是被宋之问杀的，还描绘杀人细节：“使奴以土囊压杀于别舍”。韦绚的《宾客嘉话录》也没含糊：“刘希夷诗曰：年年岁岁花相似，岁岁年年人不同。其舅宋之问苦爱此两句，知其未示人，恳乞，许而不与。之问怒，以土袋压杀之。”

我怀疑这两书作者一起躲床底下偷听来着。

宋之问洗不白是肯定的。但真相到底怎样，到现在也没人知道。

估计以后，还是会弄清的，毕竟一百年以后，名侦探柯南差不多也就上二年级，有大把时间寻找真相。
